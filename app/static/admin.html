接口接入说明 支持 Python、curl 等脚本并发调用

接口地址

  • GET /v1/models 查询模型及可用状态。
  • POST /v1/images/generations 文字生成图片。
  • POST /v1/images/edits 多参考图生成，使用 JSON 字段 image_data_urls。

鉴权：Authorization: Bearer 你的密钥。每个请求生成 1 张，脚本同时发送多个请求即可并发。请将并发数设为密钥上限以内。

默认返回 b64_json。选择 response_format: "url" 时，下载返回的图片地址也需要携带同一管理员的 API 密钥。

每张图使用独立的 Idempotency-Key。网络中断后，先查看出图记录；使用相同请求编号重试可避免重复扣费。达到并发上限返回 HTTP 429，本次不会扣费。

请求示例

示例中的 gpt-image-2 对应“GPT Image 2.5 · 标准”的接口 ID。其它模型以模型列表为准。
